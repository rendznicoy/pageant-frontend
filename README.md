# Web-Based Pageant Scoring System – Frontend

This is the frontend of the web-based pageant scoring and tabulation system for Visayas State University, built with Vue.js and Tailwind CSS. It provides separate interfaces for admin, judges, and tabulators, enabling real-time score input, display, and report viewing.

## Features

- Responsive and mobile-friendly UI using Tailwind CSS
- Role-based access for admins, judges, and tabulators
- Real-time score synchronization via WebSockets with Pusher
- Dynamic candidate display and scoring interface
- PDF viewing and printing support

## Technologies Used

- **Framework**: Vue 3
- **Styling**: Tailwind CSS
- **State Management**: Pinia
- **Routing**: Vue Router
- **Real-Time Updates**: Pusher
- **PDF Support**: iframe or viewer plugins (for report preview)
